# ZAPFIT-v0.8.9+39

## Исправления

- **Лента:** ошибка загрузки больше не даёт вечный спиннер — пагинация останавливается, вверху показывается баннер с текстом ошибки и кнопкой «Повторить».
- **Снаряжение:** детали грузятся параллельно, а не по очереди — экран открывается в разы быстрее при шторме 401.
- **Сессии:** на сервере ротация refresh-токенов с детектом reuse — параллельный рефреш из фона убивал семью токенов. Приложение теперь переживает такие циклы без зависших экранов.

## Диагностика

- Причина «крутит и не грузит»: access-токен протухает, рефреш падает в reuse-инвалидацию, каждый запрос платил фоновым логином через MFA (~7 сек), а лента/снаряжение ждали последовательно.
