# ZAPFIT-v0.8.9+38

## Новые возможности

- **Проверка обновлений:** приложение само проверяет новые версии на GitHub при запуске (не чаще раза в сутки, тихо). На странице «О приложении» — карточка «Обновления» с кнопкой ручной проверки.
- **Диалог обновления:** при найденной версии — стильное окно с переходом версий (текущая → новая), датой, размером APK, описанием релиза и кнопкой «Скачать».
- **Вкладка «Подготовка»:** соревнования локально, дни до старта, рекомендации по отдыху и тейперу, готовность по 28 дням, план добора, ИИ-разбор подготовки.
- **Соревнования: этапы и календарь:** пуш-напоминания 14/7/3/1 день, тейпер и день гонки; финиш с местом и результатом; экспорт старта в календарь через системный Intent (без лишних разрешений).
- **Фото снаряжения:** галерея всех фото, выбор нескольких, удаление с сервера и из базы, чистка дублей.

## Улучшения

- **GPS на Samsung (офлайн):** возврат к LocationSettings без timeLimit, фильтр вело clamp(0,2), порог Kalman acc*3+50, лимиты вело (скорость до 35, дистанция 0.5/1.2) — трек 4.12 км больше не схлопывается до 0.06 км.
- **Офлайн-карты:** кешируется любой просмотренный тайл (не только при записи), автокаталог `_auto`, лимит 5000 файлов/300 МБ, очистка автокеша с экрана загрузки.
- **Скорость:** DouglasPeucker и GPX-парс в isolates, пересчёт дистанции в фоне — интерфейс не виснет на длинных треках.
- **База данных:** индексы `idx_points_activity_timestamp`, `idx_activities_ended/kind/upload` (v34) — списки и выгрузки быстрее.
- **Прогноз гонки:** время и дистанция сохраняются и подхватываются при открытии.
- **Виджеты:** компактные layouts (цифры меньше, отступы 8dp, высота 90dp).

## Исправления

- **Краши из логов:** guard `activityId != null` на экране карты; `MainActivity` переведён на `FlutterFragmentActivity` (требование health-плагина).
- **Проверка разрешений:** контроль Precise vs Approximate + `locationAlways` перед фоновым трекингом.

## Локализация

- Новые строки обновлений, подготовки и соревнований — на русском и английском, переключаются автоматически.
