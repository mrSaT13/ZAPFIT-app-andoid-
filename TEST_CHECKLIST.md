# Чеклист тестирования ZAPFIT v0.6.0+15
# Дата: 15.07.2026

---

## 1. СЕРТИФИКАТЫ И ПОДКЛЮЧЕНИЕ К СЕРВЕРУ

- [ ] Установить APK на телефон
- [ ] Ввести URL/demo-сервера и нажать Подключиться
- [ ] Ввести логин: admin, пароль: admin
- [ ] **ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:** Нет ошибки "сертификат", успешный вход
- [ ] **ПРОВЕРИТЬ:** Нет бесконечного "Офлайн" — статус меняется на "Онлайн"
- [ ] **ПРОВЕРИТЬ:** Профиль загружается без 401 ошибки
- [ ] Проверить что бейдж уведомлений (красная цифра) отображается на иконке колокольчика

---

## 2. УВЕДОМЛЕНИЯ — ТИПЫ И ОТОБРАЖЕНИЕ

- [ ] Открыть экран уведомлений (колокольчик в ленте)
- [ ] **ПРОВЕРИТЬ:** Иконки и цвета соответствуют типам:
  - type 1 (Новая активность) — зелёный фитнес
  - type 2 (Дубликат) — оранжевый копия
  - type 11 (Запрос подписки) — синий person_add
  - type 12 (Подписка принята) — бирюзовый how_to_reg
  - type 21 (Garmin истёк) — красный watch_off
  - type 101 (Заявка на регистрацию) — фиолетовый approval
- [ ] **ПРОВЕРИТЬ:** Текст уведомления корректный (не "Уведомление" для неизвестных типов)
- [ ] Нажать на уведомление — появляется диалог с деталями
- [ ] Смахнуть уведомление влево — отмечается как прочитанное
- [ ] Нажать "Все прочитано" — все отмечаются прочитанными
- [ ] Кнопка "Показать все" — показывает все включая прочитанные

---

## 4. GPS ТРЕКИНГ — ФОНОВАЯ РАБОТА

### Базовый тест:
- [ ] Открыть карту, начать запись активности (бег/велосипед)
- [ ] **ПРОВЕРИТЬ:** Трек рисуется на карте, дистанция считается
- [ ] Заблокировать телефон (экран выкл)
- [ ] Подождать 2-3 минуты (пройти/проехать отрезок)
- [ ] Разблокировать телефон
- [ ] **ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:**
  - Полилиния НЕ откатывается назад (нет визуального "прыжка")
  - Дистанция НЕ дублируется (сравни с браслетом — расхождение < 10%)
  - Маркер на карте обновляется к текущей позиции через 3-5 сек после разблокировки

### Тест дедупликации:
- [ ] Во время записи: включить/выключить экран 3-4 раза
- [ ] **ПРОВЕРИТЬ:** Нет лишних точек в треке, нет рывков дистанции

## 5. GPX ИМПОРТ — ПУЛЬС

### Подготовка:
- [ ] Иметь GPX-файл с данными пульса (из Garmin/Strava/другого приложения)

### Импорт:
- [ ] Перейти в Настройки → Импорт GPX
- [ ] Выбрать GPX-файл с пульсом
- [ ] **ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:** Активность создана

### Проверка в ленте:
- [ ] Открыть ленту (Моя лента)
- [ ] Найти импортированную активность
- [ ] **ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:** Карточка показывает ЧСС (значение + "чс")

### Проверка в деталях:
- [ ] Нажать на импортированную активность
- [ ] **ПРОВЕРИТЬ:** Средний пульс и максимальный пульс отображаются
- [ ] **ПРОВЕРИТЬ:** График пульса (если есть) отображается корректно

### Проверка TCX:
- [ ] Повторить тест с TCX-файлом (если есть)

## 6. РЕДАКТИРОВАНИЕ АКТИВНОСТИ

### Через список активностей:
- [ ] Открыть список активностей
- [ ] Выбрать активность → Редактировать
- [ ] Изменить название активности
- [ ] Сохранить
- [ ] **ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:** Список обновляется с новым названием

### Через детали:
- [ ] Открыть детали активности
- [ ] Нажать иконку редактирования (карандаш)
- [ ] Изменить название или описание
- [ ] Сохранить
- [ ] **ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:** Детали обновляются

### Через ленту:
- [ ] После редактирования перейти на вкладку "Лента"
- [ ] Найти отредактированную активность
- [ ] **ОЖИДАЕМЫЙ РЕЗУЛЬТАТ:** Лента показывает новые данные (не старые)
- [ ] Если отредактировали локально (офлайн) — лента показывает локальную версию

## ОШИБКИ ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

1. **401 ошибка** → Проверь URL сервера, попробуй войти заново
2. **Сертификат** → Должно быть исправлено. Если нет — напиши
3. **GPS прыжает** → Проверь что телефон не в "Экономии батареи" (режим может убивать GPS)
4. **Пульс не показывается** → Проверь что GPX содержит теги `<gpxtpx:hr>` или `<hr>`
5. **Лента не обновляется** → Сделай pull-to-refresh (пока нет auto-refresh при возврате на вкладку)
