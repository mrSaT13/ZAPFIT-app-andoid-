ШАГ 5. ЗАГРУЗКА НА GITHUB
--------------------------------------
1. Зайди на github.com
2. Создай новый репозиторий: "ZAPFIT" (или любое имя)
3. Выбери "Public" (или Private если хочешь скрыть)
4. НЕ ставь галочки "Add README", ".gitignore" — у нас уже есть
5. Нажми "Create repository"
6. На странице репо нажми "uploading an existing file"
7. Перетащи папку endurain-flutter целиком
8. Дождись загрузки (может занять 2-5 минут)
9. Нажми "Commit changes"

⚠️ ВАЖНО: При загрузке папкой GitHub НЕ отправляет:
  - Папки из .gitignore (build/, .dart_tool/, .gradle_home/, backups/)
  - Файлы .apk
  - Файлы .keystore
Но .gitignore файл всё равно нужен для будущих pull/push через git.
