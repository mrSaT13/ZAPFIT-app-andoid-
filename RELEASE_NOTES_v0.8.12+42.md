# ZAPFIT v0.8.12+42 — 2026-11-11
## Сводка здоровья — пульс и питание
- dashboard_tab.dart: новые карточки Пульс (live BPM с BLE-датчика через BluetoothSensorService.heartRate, без датчика — последний замер из истории с датой/временем, цвет по зонам) и Питание (калории + БЖУ за сегодня; серверная сводка, офлайн — локальный кэш sqflite). Тап → соответствующий таб.
- Порядок Сводки: Вес → Сон → Вода → Шаги → Пульс → Питание → Метрики формы.

## Таб-бар Здоровья на всю ширину
- health_screen.dart: isScrollable: false + indicatorSize: tab — 7 табов делят ширину поровну, пустоты по краям больше нет.

## Шаги без ручных кнопок
- health_service.dart: троттл автоимпорта был 30 мин — добавлен quickImportFromHealthConnect (шаги+пульс+вес за 2 дня, троттл 2 мин): при открытии вкладки, каждые 3 мин пока открыта, и на resume приложения.

## Силовые теперь в метриках формы (TSB/CTL/ATL)
- training_metrics_service.dart: TSS силовой сессии по методу Фостера (длительность × средний RPE подходов; без длительности — оценка из калорий), включён в CTL/ATL/TSB и график формы за 90/30 дней.
- workouts_screen.dart журнал: в карточках сессий теперь упражнений · подходов · повторов · объём кг · мин · TSS · ккал · RPE.

## Динамический TDEE
- dashboard_tab.dart: уровень активности считается по реальным активным минутам за неделю (шаги + силовые): <75 мин лёгкий, <150 умеренный, <300 высокий, далее очень высокий. BMI/TDEE/БЖУ пересчитываются автоматически.

## HRV (rmssd) из Health Connect
- health_connect_service.dart: тип HEART_RATE_VARIABILITY_RMSSD в разрешениях + fetchHrv; «Восстановление» и «Стресс» в ZAPFIT-метриках берут HRV из часов (приоритет над ручной настройкой).
- Внимание: после обновления один раз переподтвердить разрешения Health Connect (добавился новый тип) — приложение покажет баннер.
